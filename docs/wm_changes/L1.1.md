# L1.1 - VAE 低像素输入基线

目的：保持 Wan2.2 VAE 与 Fast-WAM DiT 均冻结，仅将进入 VAE 的双相机输入由 224x448 改为 192x384。此分支不训练、不蒸馏、不改模型结构。

## 唯一需要的配置修改

文件：`configs/data/libero_2cam.yaml`

| 原行 | 修改为 |
|---|---|
| 13: `shape: [3, 224, 224]` | `shape: [3, 192, 192]` |
| 17: `shape: [3, 224, 224]` | `shape: [3, 192, 192]` |
| 31: `video_size: [224, 448]` | `video_size: [192, 384]` |
| 61: `size: [224, 224]` | `size: [192, 192]` |
| 65: `size: [224, 224]` | `size: [192, 192]` |

建议复制为新配置 `configs/data/libero_2cam192.yaml`，不要直接覆盖原配置。评测使用这个数据配置和官方 Fast-WAM checkpoint；不训练 VAE 或 DiT。

## 验收

1. 评测输入为两个 192x192 相机图像横向拼接后的 192x384 图像。
2. 完整路径为：低像素图像 -> 冻结 Wan2.2 VAE -> 冻结 Fast-WAM DiT -> LIBERO 动作。
3. 记录 LIBERO 成功率、VAE 编码耗时、端到端动作推理延迟和显存。
