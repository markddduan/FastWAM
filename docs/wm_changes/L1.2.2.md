# L1.2.2 - 轻量 Student VAE Encoder

目的：冻结 Teacher Wan2.2 VAE 与 Fast-WAM DiT；训练一个参数更少、仅部署 Encoder 的 Student VAE。Teacher 输入 224x448、9 帧；Student 输入 192x384、9 帧。

## 必改文件与行级改动

### 1. 共用双分辨率数据
文件：`src/fastwam/datasets/lerobot/robot_video_dataset.py`

沿用 L1.2.1 的四处修改：构造函数第 28-50 行新增 teacher/student 尺寸；第 85-93 行建立两套 transform；第 206-211 行生成双视频；第 232-247 行返回 `teacher_video` 与 `student_video`。

### 2. 新增学生 Encoder
新文件：`src/fastwam/models/wan22/student_vae.py`

- 新建 `StudentVAEEncoder(nn.Module)`，只实现 Encoder forward，不实现部署用 Decoder。
- 内部宽度减小、残差块减少；最终 latent 的 channel 数与教师 latent 一致。
- 第一版不引入 MoE、Router 或重建 Decoder。

### 3. 接入 FastWAM
文件：`src/fastwam/models/wan22/fastwam.py`

- 第 94-186 行的模型创建/构造函数：读取 `student_vae` 配置并实例化 `self.student_vae`；Teacher VAE 保持冻结。
- 第 247-273 行：Teacher 使用无梯度编码；Student 使用 `self.student_vae(student_video)`，允许反向传播。
- 第 522 行前：新增 `vae_distill_loss(sample)`：
  `L_latent = MSE(student_latent, adaptive_avg_pool3d(teacher_latent))`；
  `L_temporal = MSE(delta(student_latent), delta(target_latent))`；
  `L = L_latent + 0.1 * L_temporal`。
- 推理的图像编码入口必须改为 Student Encoder；Teacher 仅训练期存在。
- 第 1199-1230 行：checkpoint 保存/加载 `student_vae` state_dict，不能只保存 mot。

### 4. 训练器
文件：`src/fastwam/trainer.py`

- 第 82-94 行：冻结全模型，只将 `model.student_vae.parameters()` 交给优化器。
- 第 132、415、697 行：调用 `compute_loss(sample)`，VAE 模式执行蒸馏损失。
- 第 669-670 行：VAE-only 模式不得重新打开 DiT。
- 内部验证仅记录 latent MSE、temporal MSE、学生编码耗时与显存。

### 5. 配置与推理

新建 `configs/model/fastwam_student_vae_distill.yaml` 和对应 task YAML，包含 `train_target: vae`、学生结构超参数、`lambda_latent: 1.0`、`lambda_temporal: 0.1`。

LIBERO 评测保持 `EVALUATION.visualize_future_video=false`，因为部署模型只有学生 Encoder；完整动作路径是 Student VAE -> 冻结 DiT -> LIBERO。

## 验收

先比较 latent MSE / temporal MSE、参数量、VAE 编码延迟和显存；最终比较完整冻结 DiT 下的 LIBERO 成功率。
