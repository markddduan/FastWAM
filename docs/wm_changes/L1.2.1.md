# L1.2.1 - 原结构 VAE Encoder 微调

目的：冻结 Fast-WAM DiT，只微调由 Wan2.2 初始化的 Student VAE Encoder。Teacher VAE 接收 224x448、9 帧；Student 接收 192x384、9 帧。唯一训练监督为 latent 蒸馏。

## 必改文件与行级改动

### 1. 双分辨率训练样本
文件：`src/fastwam/datasets/lerobot/robot_video_dataset.py`

- 构造函数第 28-50 行：新增 `teacher_video_size` 与 `student_video_size` 参数。
- 第 85-93 行：保留现有 resize/crop/normalize；额外建立 teacher 和 student 两套 transform。
- 第 206-211 行：由单一 `video` 转为同一拼接原视频的 `teacher_video` 和 `student_video`。
- 第 232-247 行：返回字典新增 `teacher_video`、`student_video`；不删除 action/proprio/context 键。

### 2. VAE 编码与蒸馏损失
文件：`src/fastwam/models/wan22/fastwam.py`

- 第 247-260 行：保留带 `@torch.no_grad()` 的教师编码；新增不带 `no_grad`、不走 cudagraph 的学生编码函数。
- 第 522 行前：新增 `vae_distill_loss(sample)`：教师 latent 下采样为学生 latent 网格，使用 `MSE(student, target)`。
- 新增 `compute_loss(sample)`：VAE 模式调用 `vae_distill_loss`，原模式仍调用 `training_loss`。

### 3. 冻结 DiT，只优化 VAE Encoder
文件：`src/fastwam/trainer.py`

- 第 82-94 行：替换 `_apply_dit_only_train_mode` 和 `model.dit.parameters()`。新模式冻结全模型，只打开 `model.vae.model.encoder` 与 `model.vae.model.conv1`；优化器仅接收这两部分参数。
- 第 132、415、697 行：将 `training_loss(sample)` 改为 `compute_loss(sample)`。
- 第 669-670 行：按 `train_target: vae` 进入 VAE-only 模式，避免训练循环重新打开 DiT。
- VAE 蒸馏阶段的内部验证只记录 latent MSE；不调用未来视频 decode 或 DiT action 验证。

### 4. 保存和评测
文件：`src/fastwam/models/wan22/fastwam.py`

- 第 1199-1209 行：checkpoint 新增 `vae_encoder`（encoder + conv1）权重。
- 第 1211-1230 行：若 checkpoint 含 `vae_encoder`，加载至 Student VAE。

## 新配置

新增 task/model 配置指定：`train_target: vae`、`teacher_video_size: [224,448]`、`student_video_size: [192,384]`、`lambda_latent: 1.0`。DiT 始终冻结。

## 验收

训练/验证：latent MSE。最终：Student VAE -> 冻结 DiT -> LIBERO 成功率、VAE 编码延迟和显存。
